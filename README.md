# config

纯自用代理配置，不含节点。

| 目录 | 软件 |
|---|---|
| [egern](egern) | Egern |
| [surge](surge) | Surge |
| [loon](loon) | Loon |
| [qx](qx) | Quantumult X |

各目录下的 `rules/` 由 GitHub Actions 每天北京时间 4:30 同步生成。

## 来源与许可

- 规则集来自 [MagicRule](https://magicrule.pages.dev)
- 去广告规则另并入 [fmz200/wool_scripts](https://github.com/fmz200/wool_scripts) 的广告拦截&净化合集、HTTPDNS 拦截器（GPL-3.0），以及[可莉](https://github.com/luestr/ProxyResource)的广告平台拦截器（经 [Romeo](https://github.com/ifflagged/Romeo) 转换）
- 配置引用的模块和插件来自 fmz200、[ddgksf2013](https://github.com/ddgksf2013)（墨鱼，Loon 版经 Romeo 转换）、[TributePaulWalker](https://github.com/TributePaulWalker/Profiles)、[可莉](https://github.com/luestr/ProxyResource)，版权归原作者
