- 规则集来自 [MagicRule](https://magicrule.pages.dev)
- 去广告规则另并入 [fmz200/wool_scripts](https://github.com/fmz200/wool_scripts) 的广告拦截&净化合集、HTTPDNS 拦截器（GPL-3.0），以及[可莉](https://github.com/luestr/ProxyResource)的广告平台拦截器（经 [Romeo](https://github.com/ifflagged/Romeo) 转换）
- 配置引用的模块来自 fmz200、[ddgksf2013](https://github.com/ddgksf2013)（墨鱼）、[TributePaulWalker](https://github.com/TributePaulWalker/Profiles)，版权归原作者

含 fmz200 内容的规则集按 GPL-3.0 发布。原作者如有异议，请提 Issue，收到后撤下对应内容。
